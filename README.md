# Banking Analytics Dashboard (Interactive Creation Using Power BI)

## Overall Project Objective

The objective of this project is to develop a Banking Analytics Dashboard in Power BI that provides meaningful insights into banking operations. By analyzing customer accounts, transactions, loans, cards, branch performance, and financial metrics, the dashboard enables stakeholders to monitor business performance, identify trends, and make data-driven decisions to improve operational efficiency and customer service.

# Process

1. Data Collection – Imported the Banking dataset into Power BI.
2. Data Cleaning – Cleaned and transformed the data using Power Query by handling missing values, correcting data types, and removing inconsistencies.
3. Data Modeling – Built a star schema by creating relationships between Customers, Accounts, Transactions, Loans, Cards, Branches, and Date tables.
4. DAX Calculations – Created measures to calculate Total Balance, Total Customers, Transaction Amount, Total Loan Amount, Active Loans, Loan Approval Rate, Average Customer Balance, and Cards Issued.
5. Dashboard Development – Designed interactive dashboards using Cards, Line Charts, Column Charts, Bar Charts, Donut Charts, Maps, Matrix visuals, and Slicers.
6. Business Analysis – Analyzed branch performance, customer behavior, loan portfolio, transaction trends, and financial KPIs to generate actionable business insights.

# Project Insights

## Dashboard 1: Executive Dashboard

This dashboard provides an overall view of banking performance through key financial and operational KPIs.

### Insights

- Monitors total balance, customers, loans, and transaction amount.
- Tracks monthly transaction trends.
- Compares branch-wise financial performance.
- Analyzes loan distribution across loan categories.
- Supports executive-level business decision-making.

---

## Dashboard 2: Geographic Dashboard

This dashboard analyzes banking performance across different branch locations.

### Insights

- Displays branch distribution across cities.
- Compares branch-wise balance and transaction performance.
- Identifies top-performing cities and branches.
- Supports regional business analysis and planning.
- Enables geographical performance comparison.

---

## Dashboard 3: Customer Dashboard

This dashboard provides insights into customer accounts and financial activities.

### Insights

- Displays customer account information and balances.
- Analyzes account type distribution.
- Identifies high-value customers.
- Tracks customer growth and financial performance.
- Supports customer segmentation and relationship analysis.

---

## Dashboard 4: Loan Dashboard

This dashboard evaluates lending performance and card services.

### Insights

- Tracks active loans and loan approval rate.
- Analyzes loan amount by loan category.
- Monitors card issuance by card type.
- Evaluates lending performance across branches.
- Supports loan portfolio and customer service analysis.
